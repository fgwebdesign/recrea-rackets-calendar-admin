================================================================================
                            🎽 SISTEMA DE TALLES DE REMERA
================================================================================

📋 DESCRIPCIÓN GENERAL:
Se implementó un sistema completo para manejo de talles de remera en torneos,
permitiendo a los administradores configurar si un torneo incluye remeras
y a los jugadores seleccionar sus talles durante la inscripción.

================================================================================
                               🗄️ CAMBIOS EN BASE DE DATOS
================================================================================

1️⃣ TABLA: tournament_info
   ✅ NUEVO CAMPO: requires_shirts
   - Tipo: boolean
   - Default: false
   - Descripción: Indica si el torneo requiere selección de talles de remera

2️⃣ TABLA: tournament_teams  
   ✅ NUEVO CAMPO: shirt_sizes
   - Tipo: jsonb
   - Default: []
   - Descripción: Array de talles seleccionados por los jugadores
   - Validación: Entre 1 y 2 talles, valores válidos: XS, S, M, L, XL, XXL

================================================================================
                               🔧 CAMBIOS EN CONTROLADORES
================================================================================

1️⃣ TOURNAMENT.CONTROLLER.JS:

   📝 FUNCIÓN: createTournament()
   ✅ NUEVO PARÁMETRO: requires_shirts (opcional, default: false)
   ✅ LÓGICA: Guarda el campo en tournament_info al crear el torneo
   
   📝 FUNCIÓN: joinTournament()
   ✅ NUEVO PARÁMETRO: shirt_sizes (condicional)
   ✅ VALIDACIÓN CONDICIONAL:
      - Si requires_shirts = true → shirt_sizes es OBLIGATORIO
      - Si requires_shirts = false → shirt_sizes NO debe enviarse
   ✅ VALIDACIONES DE TALLES:
      - Array con 1-2 elementos
      - Solo talles válidos: XS, S, M, L, XL, XXL
      - Permite duplicados (ej: ["M", "M"])
   
   📝 FUNCIÓN: adminRegisterTeam()
   ✅ MISMA LÓGICA que joinTournament()
   ✅ Validación condicional idéntica
   ✅ Inserción condicional de shirt_sizes

================================================================================
                               📡 NUEVOS ENDPOINTS Y PARÁMETROS
================================================================================

1️⃣ CREAR TORNEO:
   POST /api/tournaments
   ✅ NUEVO PARÁMETRO: requires_shirts (boolean, opcional)
   
   Ejemplo:
   {
     "name": "Torneo con Remeras",
     "requires_shirts": true,
     "categories": [...],
     ...
   }

2️⃣ INSCRIBIRSE EN TORNEO:
   POST /api/tournaments/:id/join
   ✅ NUEVO PARÁMETRO: shirt_sizes (array, condicional)
   
   Ejemplo CON remeras:
   {
     "userId1": "uuid1",
     "userId2": "uuid2", 
     "unavailable_time_slot": "slot-id",
     "shirt_sizes": ["M", "L"]
   }
   
   Ejemplo SIN remeras:
   {
     "userId1": "uuid1",
     "userId2": "uuid2",
     "unavailable_time_slot": "slot-id"
   }

3️⃣ REGISTRO ADMINISTRATIVO:
   POST /api/tournaments/:id/admin/register-team
   ✅ MISMA LÓGICA que inscripción normal

================================================================================
                               ✅ VALIDACIONES IMPLEMENTADAS
================================================================================

1️⃣ VALIDACIONES DE TALLES:
   ✅ Solo talles válidos: XS, S, M, L, XL, XXL
   ✅ Entre 1 y 2 talles por equipo
   ✅ Permite talles duplicados (mismo talle para ambos jugadores)
   ✅ Array obligatorio si el torneo requiere remeras

2️⃣ VALIDACIONES CONDICIONALES:
   ✅ Si requires_shirts = true → shirt_sizes es OBLIGATORIO
   ✅ Si requires_shirts = false → shirt_sizes NO debe enviarse
   ✅ Mensajes de error específicos según el caso

3️⃣ VALIDACIONES DE BASE DE DATOS:
   ✅ Constraint JSONB para shirt_sizes
   ✅ Campo boolean para requires_shirts
   ✅ Índices GIN para optimización de queries JSONB

================================================================================
                               📊 CASOS DE USO SOPORTADOS
================================================================================

1️⃣ TORNEO CON REMERAS:
   ✅ Admin marca requires_shirts = true
   ✅ Jugadores DEBEN seleccionar talles al inscribirse
   ✅ Sistema valida talles y los guarda en BD
   ✅ Posible generar reportes de talles por torneo

2️⃣ TORNEO SIN REMERAS:
   ✅ Admin deja requires_shirts = false (default)
   ✅ Jugadores NO necesitan seleccionar talles
   ✅ Sistema ignora cualquier shirt_sizes enviado
   ✅ Compatible con torneos existentes

3️⃣ CASOS ESPECIALES:
   ✅ Equipos de 1 jugador (solo 1 talle)
   ✅ Equipos de 2 jugadores (2 talles, pueden ser iguales)
   ✅ Talle único para ambos jugadores ["M", "M"]

                               🔍 RESPUESTA A PREGUNTA ESPECÍFICA
================================================================================

❓ "¿En los get@tournamentInfo.controller.js tenemos agregado el size?"

✅ RESPUESTA: NO, el controlador tournamentInfo.controller.js NO fue modificado.

📋 RAZÓN: 
- Los talles se manejan en tournament_teams (nivel de equipo)
- tournament_info solo maneja información general del torneo
- El campo requires_shirts se obtiene automáticamente en las queries de tournament.controller.js
- No se necesita modificar tournamentInfo.controller.js

📡 CÓMO SE OBTIENEN LOS TALLES:
- Los talles se obtienen en las queries de tournament.controller.js
- Se incluyen en las respuestas de getTournamentById(), getTournamentTeams(), etc.
- No se necesita endpoint específico en tournamentInfo.controller.js
